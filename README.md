# Song Bottle

노래 하나를 보내고, 낯선 누군가의 음악을 받는 익명 음악 교환 웹앱입니다.

**실제 사용자 간 교환 버전입니다.** 준비된 가짜 상대나 샘플 교환 기록을 사용하지 않습니다.

## 실행

Node.js 22.16 이상이 필요합니다. 현재 개발 PC에서는 22.17로 검증했습니다.

```sh
npm install
npm run dev
```

기본 주소는 http://localhost:5173 입니다. 포트가 사용 중이면 `PORT` 환경 변수를 바꿉니다.

PowerShell 예시:

```powershell
$env:PORT = '5174'
npm run dev
```

## 제출 시연

1. 일반 브라우저와 시크릿 창을 각각 엽니다. 동일 브라우저의 일반 탭들은 같은 사용자입니다.
2. 각 창에서 서로 다른 음악 URL을 입력합니다.
3. 양쪽에서 `밤` 등 같은 무드를 하나 이상 선택합니다.
4. 해류 코드도 같게 맞춥니다. 둘 다 비워두어도 됩니다.
5. 첫 번째 사람은 대기하고, 두 번째 사람이 보내면 교환됩니다.
6. 첫 번째 화면에도 최대 약 4초 뒤 결과가 도착합니다.
7. 교환 기록, 플레이리스트, 즐겨찾기, 텍스트 내려받기를 확인합니다.

다른 PC/휴대폰에서는 배포된 동일한 HTTPS 주소를 사용해야 합니다.

## 수정할 위치

| 바꾸려는 내용                     | 파일                    |
| --------------------------------- | ----------------------- |
| 무드 목록, 제한 시간, 메시지 길이 | `shared/rules.js`       |
| 첫 화면 문구, 입력 순서           | `src/pages/Home.tsx`    |
| 교환 기록과 플레이리스트          | `src/pages/Library.tsx` |
| 메뉴, 설정, 교환 결과, 이용 안내  | `src/App.tsx`           |
| 색상, 크기, 모바일 간격           | `src/styles.css`        |
| 곡 정보 공통 표시                 | `src/components.tsx`    |
| 브라우저와 서버 통신              | `src/api.ts`            |
| 교환 조건, DB 저장 방식           | `server/store.js`       |
| API 경로, 인증, 요청 제한         | `server/app.js`         |
| 서버 실행과 배포 포트             | `server/index.js`       |

핵심 규칙 앞에 한국어 주석을 달았으며 Prettier로 들여쓰기와 줄바꿈을 통일합니다.

## 교환 규칙

- 서로 다른 사용자의 서로 다른 곡을 1:1로 교환합니다.
- 무드가 하나 이상 겹치고 해류 코드가 같아야 합니다.
- 가장 오래 기다린 적합한 보틀부터 교환합니다.
- 한 사용자당 대기 보틀은 하나입니다. 기록에서 회수할 수 있습니다.
- 같은 곡은 발송 시각부터 1시간 이후에 다시 보낼 수 있습니다. 회수해도 제한은 유지됩니다.
- 대기 보틀은 7일 뒤 만료됩니다. 상태는 다음 API 요청 때 갱신합니다.
- 교환 내용은 SQLite에 저장합니다. 새로고침과 서버 재시작 후에도 유지됩니다.

## 검증

```sh
npm test
npm run build
node tests/browser.mjs
```

마지막 명령은 설치된 Google Chrome을 사용합니다. 브라우저 테스트는 별도 메모리 DB에서 실행되어 실제 사용자 기록을 수정하지 않습니다.

## 배포

```sh
npm ci
npm run build
npm start
```

`DEPLOYMENT.md`를 참고하세요. 정적 파일만 올리면 실제 교환 API는 작동하지 않습니다.

## 현재 범위

곡 제목은 직접 입력합니다. 음원 스트리밍과 자동 메타데이터 조회 대신 검증된 플랫폼 링크를 원래 서비스에서 엽니다. 짧은 리디렉션 링크 중 `spotify.link`, `on.soundcloud.com` 등은 지원하지 않습니다.

익명 접속 키는 브라우저에 저장되어 기기 간 동기화·계정 복구가 없습니다. 곡과 메시지는 사용자 입력 텍스트로만 표시합니다. 신고는 DB에 저장되고 신고자 화면에서 숨겨지며 자동 전역 차단은 하지 않습니다.

현재 설정 안내는 실제 저장 동작을 설명하는 안내문입니다. 공개 장기 운영 전에는 운영자 연락처, 데이터 삭제 절차와 신고 관리 화면을 추가해야 합니다.
